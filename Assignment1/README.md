# AndroidProgrammingQuiz-CrossPlatformCI

A rotating-triangle OpenGL ES 3.0 renderer that builds and runs on three
platforms — Desktop (Windows), Android, and Web (WebAssembly) — from one
shared `Scene/` codebase, using a `Model` + `Renderer` architecture.

## Prerequisites

- **Desktop:** CMake 3.15+, Visual Studio 2022 (Desktop development with C++)
- **Android:** Android Studio, with NDK (Side by side) and CMake installed via
  SDK Manager → SDK Tools
- **Web:** Emscripten SDK (`emsdk`), activated in your terminal session

## Build & Run — Desktop

From the project root:

```
script_build_and_run.bat
```

This configures, builds, and launches the app automatically. Press **ESC**
to quit. Re-running the script always does a clean rebuild.

## Build & Run — Android

1. Open Android Studio
2. **File → Open**, select the `android/` folder (not the project root)
3. Wait for Gradle sync to finish
4. Click **Run ▶** with an emulator or device selected

## Build & Run — Web

1. Activate Emscripten in your terminal (once per session):
   ```
   C:\emsdk\emsdk_env.bat
   ```
2. From the project root, in that same terminal:
   ```
   build_web.bat
   ```
3. Serve and open it:
   ```
   cd web
   python -m http.server 8080
   ```
   Then open `http://localhost:8080/` in a browser.

## Project Layout

```
Scene/            Shared C++ source (Model, Renderer, ShaderHelper, Triangle, Square, main.cpp)
android/           Android Studio / Gradle project (uses Scene/ via NativeTemplate.cpp)
CMakeLists.txt     Desktop build entry point
build_web.bat/.sh  Web build entry point (Emscripten)
```

`build_desktop/` and `web/` are build output folders, not source — they're
regenerated by the build scripts and should not be committed or submitted.
